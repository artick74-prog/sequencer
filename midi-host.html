Rhythm Editor LIVE
Selected hit none
LIVE preview is always on. Click an empty step to add an attack; click a hit to select it. Drag a hit left/right to move it. Use the length buttons for 1/32, 1/16, dotted 1/16, 1/8, dotted 1/8, 1/4, dotted 1/4 and longer values. Notes never overlap in the editor: if a new/moved attack lands before the previous note ends, the previous note is automatically shortened exactly to the new attack. The global Gate control still scales these stored lengths during playback. Changes are heard immediately but are not saved until you press Save as new revision.
