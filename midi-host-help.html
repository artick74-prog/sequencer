Важно: General MIDI задаёт номера и общие назначения MIDI-контроллеров, но не гарантирует, что конкретный SoundFont, VST или железный синтезатор одинаково реагирует на каждый CC. Ниже — практические рекомендации: с чего обычно имеет смысл начинать для данного типа инструмента.

Browser audio (SF2)

Встроенный SoundFont

MIDI Host по умолчанию подготавливает встроенный Yamaha XG SoundFont для браузерного прослушивания General MIDI дорожек. GM-программа берётся из выбранного инструмента дорожки, например GM 56 · Trumpet.

Свой SF2

Кнопка Load SF2… позволяет загрузить собственный файл .sf2. Переключатель Project GM tracks (SF2) включает или отключает браузерный звуковой движок независимо от Hardware MIDI Out.

Swing Grid

Swing Grid меняет геометрию quantize-сетки Piano Roll. Диапазон 0–100%: 0% — прямая сетка, 100% — классическое соотношение 2:1. Каждая вторая линия straight-grid сдвигается вправо; ноты, уже стоящие точно на текущей сетке, двигаются вместе с ней прямо при движении Swing slider. Свободные/humanized ноты между линиями остаются на месте. Snap, Draw, drag и resize используют те же сдвинутые позиции.

Apply Swing записывает позиции сетки непосредственно в MIDI note ticks. Если в Piano Roll выделены ноты, меняются только они; без выделения — весь проект. Повторное применение не накапливает дополнительный swing. Для точной настройки наведи курсор на Swing Grid и крути колесо мыши: один шаг = 1%. Ещё один Fender-подобный режим — удерживай Shift и тяни ползунок мышью: движение становится медленным и точным.

Playback использует сохранённые ticks буквально и больше не добавляет скрытый swing. Обычный MIDI export тоже передаёт реальный project timing. Для 1/8T и 1/16T Swing не применяется.

Для обмена с Fender / Studio One / Ableton в ⚙ Settings есть режим DAW exchange · Straight MIDI. Когда он включён, явный Export MIDI, экспорт отдельной дорожки и отправка в MIDI Pool временно убирают только компонент текущего Swing из экспортируемой копии — сам проект и значение Swing не меняются. MIDI, возвращённый через MIDI Pool, трактуется как straight и автоматически садится обратно на текущую Swing Grid. Свободные/humanized ноты между линиями не квантуются. Save Project / Sync to AI этот режим не меняет.

Быстрый словарь контроллеров

Исполнение

  • Velocity — сила/характер атаки ноты.
  • Pitch Bend — плавное изменение высоты.
  • Aftertouch — давление после нажатия; назначение зависит от тембра.
  • CC1 Modulation — часто vibrato/modulation.
  • CC2 Breath — дыхание/интенсивность; особенно полезен на духовых и многих современных библиотеках.
  • CC11 Expression — музыкальная динамика внутри уже звучащей партии.

Микс и педали

  • CC7 Volume — общий уровень канала.
  • CC10 Pan — панорама.
  • CC64 Sustain — sustain/damper.
  • CC65 Portamento — включение portamento, если инструмент его поддерживает.
  • CC66 Sostenuto — sostenuto.
  • CC67 Soft Pedal — soft pedal.

Тембр и эффекты

  • CC71 Resonance — resonance.
  • CC72 Release — release time.
  • CC73 Attack — attack time.
  • CC74 Brightness / Cutoff — яркость/часто filter cutoff.
  • CC75 Decay — decay time.
  • CC76/77/78 — vibrato rate/depth/delay.
  • CC91/93/94/95 — reverb/chorus/detune/phaser send.

Аккордеон · GM 21

Практический старт: Velocity, CC11 Expression, CC7 Volume, CC10 Pan, CC91 Reverb, CC93 Chorus; затем можно попробовать CC1 и Pitch Bend, если конкретный SoundFont реагирует музыкально.

TD-3 и XR20

TD-3

Для нашей дорожки отдельно есть TD-3 Slide: MIDI Host эмулирует slide перекрытием соседних нот. Остальные параметры проверяем по реакции конкретного TD-3; стандартный список CC не следует считать картой всех ручек синтезатора.

XR20

Velocity — главный выразительный параметр для ударов. Для остальных CC не предполагаем поддержку автоматически: ориентируемся на MIDI-реализацию XR20 и фактическое поведение железа.

Эта страница — рабочая шпаргалка проекта. По мере появления собственных articulation mapping, presets и проверок на железе список можно уточнять без изменения самого Piano Roll.
