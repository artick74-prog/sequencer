# Idea Pool

Idea Pool is the working layer between **Reference MIDI** and **My Styles**.

- **Reference MIDI** — external source material.
- **Idea Pool** — user-created musical fragments worth keeping even when they do not fit the current arrangement.
- **My Styles** — mature/reusable arranger-style material assembled from selected ideas.

An idea may contain one track or several tracks. Notes are stored relative to the idea start, with original timing, velocity, duration and hardware/channel metadata preserved.

## Lifecycle

- `raw` — captured experiment.
- `promising` — worth revisiting.
- `used` — already used in a project/style.
- `archive` — kept for reference.

The first entry, **IDEA-001 · Refined Chorus Acid Hook**, came from the Acid Breaks project.
